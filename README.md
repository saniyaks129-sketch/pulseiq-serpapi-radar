# Real-Time Local Intelligence Radar

Built for the SerpApi India Hackathon 2026.

## 🎯 Project Overview
Standard static AI models lack real-time local context. This application uses SerpApi to deliver real-time local intelligence on hiring trends, local news, and market shifts.

## 🚀 How SerpApi is Used
We integrate the **SerpApi Google Search API** to fetch live, structured search snippets and organic results in real time.
